# IYAWO MI — Birthday Website 🤍

A responsive, static birthday website made with HTML, CSS and vanilla JavaScript.

## Included
- Starry universe opening and cream/gold styling
- Personal birthday letter (the exact wording supplied)
- Three memories with the supplied media and captions
- 100 Reasons Why I Love You
- Five expandable Open When letters
- Four song links: “her” — JVKE; “Orente” — Adekunle Gold; “Eternity” — Alex Warren; “Olufunmi” — Styl-Plus
- Small interactive birthday surprise and wish button

## Project files
- `index.html` — page content
- `style.css` — desktop and mobile styling
- `script.js` — starfield and interactive effects
- `photos/memory-1.jpg` — first memory photo
- `photos/memory-2.mp4` — second memory video
- `photos/memory-3.mp4` — third memory video

Keep the `photos` folder alongside `index.html` when uploading or deploying. The videos use native browser controls and `playsinline` for phones.

## Preview locally
Open `index.html` in a modern browser. An internet connection is needed for the optional Google Fonts; system font fallbacks are included.

## Deploy with GitHub and Vercel
1. Create a GitHub repository, for example `iyawo-mi-birthday`.
2. Upload the contents of this folder (not the outer ZIP folder) to the repository root.
3. In Vercel, choose **Add New → Project** and import that GitHub repository.
4. Choose **Other** as the framework preset. Leave the build command empty. Use `.` as the output directory if Vercel asks for one.
5. Deploy and open the generated `*.vercel.app` URL on a phone to test it.

This is a static site and does not collect personal data.
